1. Модуль учёта времени для системы управления задачами

Проект выполнен в рамках практического задания к лекции №5
«Этапы разработки программного продукта».

2. Требования задания
1. Возможность старта/остановки таймера для задачи
2. Учёт общего затраченного времени
3. Генерация отчётов по времени
4. Интеграция с существующей системой задач

3. Дополнительные функции
- **Множественные сессии**: возможность ставить задачу на паузу и возобновлять работу
- **Плановое время (Estimated Time)**: установка ожидаемого времени и расчёт отклонений
- **Экспорт отчётов**: выгрузка аналитики в форматы `JSON` и `CSV`
- **Unit-тесты**: полное покрытие основных методов

4. Структура проекта

task-time-tracker/

├── time_tracker.py # отдельный модуль учёта времени

├── main.py # общая система задач + интеграция

├── test_time_tracker.py # unit-тесты

├── README.md # документация

└── requirements.txt # зависимости

5. Технологии: Python 3.12

6. Запуск
python main.py
python -m unittest test_time_tracker.py
